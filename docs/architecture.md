# 业务状态说明

## 报名

`pending → approved | rejected`

通过报名时创建成员、生成专属邀请码，并记录邀请人；此时不发推荐积分。

## 任务与作品

`claimed → submitted → completed | rejected`

作品从 `pending` 审核为 `approved` 时：

1. 给发布者写入 `+3` 的任务积分台账。
2. 如果这是被推荐人的首条有效任务，给邀请人写入 `+1` 的推荐积分台账。
3. 标记推荐奖励已发放，防止后续重复奖励。

## 兑换

申请兑换时先写入负积分台账进行冻结：

- 确认打款：兑换状态改为 `paid`，不再重复扣分。
- 拒绝兑换：写入等额正积分退回，兑换状态改为 `rejected`。

积分余额始终由台账求和，不直接维护一个容易与流水不一致的余额字段。
